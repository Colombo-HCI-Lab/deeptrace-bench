deeptrace-bench

Open deepfake detectors, run on South Asian audio and video under one evaluation setup. What has been scored so far, and how a score is produced.

How a score is made

Pipeline

1 · configs/

Configure

One YAML per model (upstream commit, weights, training data), per dataset (access, licence) and per evalset (what gets scored). One shared evaluation setup.

2 · setup_*.py

Set up

Pin upstream code and weight hashes. Download each dataset and build its manifest: one row per item, with label, generator and group attributes.

3 · score.py

Score

Evalset to items, shared preprocessing (4 s audio windows; SCRFD faces, per-model crops), adapter, P(fake) per item. Sharded and resumable.

4 · evaluate.py

Evaluate

AUC and EER with 95% bootstrap intervals, overall and per group. Failures (no face, too short) are counted per group, never dropped.

5 · --publish

Publish

Aggregate tables only go to results/ in git. Every row carries its pairing and contamination verdict.

Parity gateAn adapter counts only after it matches upstream code within 1e-3 on about 200 items.
Contamination guardTraining data is checked against the evalset's sources. A model that trained on the data is refused.
Publish guardPipeline tests, smoke runs and item-level files never reach git.
In gitCode, configs, docs, weight hashes, aggregate results, parity summaries.
In the store (DTB_ROOT)Datasets, weights, manifests, face caches, per-item scores. Licences forbid sharing these.

A smoke namespace runs the same steps on two real and two fake items per evalset, to prove a model or dataset is wired up. Those numbers are never reported.

Scored runs

  • The evaluation setup is proposed until the team settles decision 5, so these numbers can still move.
  • Below chance on a reproduction set means a flipped score; on a South Asian set it is a finding about the model.
  • Source overlap: the model's pretraining shares a corpus with the evalset. Reported with a warning, kept out of headlines.
  • Cross-corpus evalsets take real and fake from different corpora and never enter headline numbers.
